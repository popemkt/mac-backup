Install plugins from GitHub and from marketplaces

Terminal, kb ext (kb#110, #115, #118, #120, #123). Run on shared-server in a throwaway store, deleted afterwards
Beforekb ext had no install, update, trust or marketplace commands. Plugins had to be copied into a repo's .kb/extensions by hand.
AfterAdd a marketplace, install a plugin by name, and see it listed as untrusted with its digest. It does not run until a person approves it.
